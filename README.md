## 📋 Features

| Module | Description |
|---|---|
| 💰 **Expense Tracker** | Log expenses by category, view pie charts, get AI savings advice |
| 🛡️ **Fraud Detection** | Risk-score transactions in real time using AI rules engine |
| 🏦 **Loan Eligibility** | Instant loan assessment with factor breakdown & EMI calculator |
| 📊 **Analytics** | Spending trends, treemaps, risk summaries & key insights |

---

## 🛠️ Tech Stack

- **Frontend + Backend**: [Streamlit](https://streamlit.io/)
- **Data**: Pandas, NumPy
- **Charts**: Plotly (interactive, beautiful)
- **ML**: Scikit-learn
- **Deploy**: Streamlit Community Cloud (free)

## ⚡ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

---

## 🌐 Deploy on Streamlit Cloud (5 minutes)

1. Push this repo to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Click **"New app"** → Select your repo
4. Set **Main file**: `app.py`
5. Click **Deploy** ✅

Your app will be live at: `https://<your-username>-finguard.streamlit.app`
